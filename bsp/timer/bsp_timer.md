# Timer BSP

`TIMER_0` is generated by SysConfig as a periodic timer with a 1 MHz timer
clock and a 1 ms period.

The YueLu-style API provides `TimerStart`, `TimerStop`, `TimerReset` and
`TimerRead`. The returned counter is a raw, down-counting timer tick value.
Reset restores the counter to the configured load value. The generated
SysConfig files are the source of truth for the timer instance and period.
